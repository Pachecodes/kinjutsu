# Keep ownership explicit
Picture1 owns target identity/hair/complexion, guide owns performance/clothes/environment. Describe the observed source rather than invent actions or anatomy. Use one subject for initial test. Edit only source-specific scene details when comparing takes; keep seed/recipe fixed. Do not use additional references, max image sizing or heavier model as an automatic quality upgrade.

Default prompt requests ambience/no narration, not a speech script. Guide preparation removes source audio. Mouth trajectory following does not prove phoneme alignment. For Spanish or another language, choose first whether the owner wants original voice preserved, a licensed target voice or generated dialogue. Never claim existing output retained original voice unless separately remuxed and verified.

A source-audio remux retains the actual source speaker, not an identity-specific voice. A new TTS voice may need timing alignment/lip sync as an independently validated step. Preserve frame timestamps; do not reinterpret25FPS as24FPS. Listen and inspect synchronization across the full clip. Do not invent dialogue or clone a voice without appropriate rights/authorization.
